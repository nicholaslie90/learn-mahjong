# learn-mahjong

An interactive guide to **Hong Kong old style** mahjong (香港麻雀): every tile, the sets you build, how a round plays, faan scoring, and four practice drills.

**→ https://nicholaslie90.github.io/learn-mahjong/**

One static `index.html`. No build, no dependencies. Tiles are Unicode glyphs (U+1F000–U+1F02B), so nothing to download and nothing to keep in sync.

Payout tables and the exact faan for smaller patterns vary table to table — agree on house rules before the first deal.
